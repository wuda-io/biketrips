# Reise mit dem Radl von Wien (AT) nach Triest (IT)

## Plan

- Strecke: 570 km
- Höhenmeter: 3780 hm
- geplanter start: 2026-08-22 (Sa.)
- geplantes ende: ca. 2026-08-27

### Route

ca. 110km / tag => ca. 5 tage

## 📊 Routenübersicht

| Etappe       | Start – Ziel            | Distanz     | Höhenmeter (Aufstieg) | Charakteristik                                                 |
| :----------- | :---------------------- | :---------- | :-------------------- | :------------------------------------------------------------- |
| **Etappe 1** | Wien → Mürzzuschlag     | 100 km      | ~1.100 hm             | Flach im Wiener Becken, steiler Anstieg über den Semmeringpass |
| **Etappe 2** | Mürzzuschlag → Leibnitz | 110 km      | ~450 hm               | Überwiegend bergab/flach entlang Mürz & Mur via Graz           |
| **Etappe 3** | Leibnitz → Celje (SLO)  | 95 km       | ~650 hm               | Hügelig nach der Grenze, vorbei an Maribor ins Savinja-Tal     |
| **Etappe 4** | Celje → Postojna        | 105 km      | ~1.050 hm             | Welliges Profil über Ljubljana hinauf ins Karst-Plateau        |
| **Etappe 5** | Postojna → Triest (ITA) | 75 km       | ~350 hm               | Wunderschöne Abfahrt vom Karst hinab an die Adria              |
| **Gesamt**   | **Wien → Triest**       | **~485 km** | **~3.600 hm**         | **5 Tage Tour**                                                |

- **Navigation:** Hauptsächlich Orientierung am **EuroVelo 9** (Wien bis Maribor/Ljubljana).
